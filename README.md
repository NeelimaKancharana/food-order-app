# 🍔 Food Order App

A responsive food ordering web application built using React.  
Users can browse meals, add items to the cart, adjust quantities, and submit an order.

## 📌 Overview

The Food Order App is a frontend-focused React project that demonstrates state management, component-based architecture, and dynamic UI updates. The application simulates a real-world food ordering system with cart functionality and order submission handling.

## 🚀 Features

- Browse available food items
- Add items to cart
- Increase / Decrease item quantity
- Remove items from cart
- Automatic total price calculation
- Order summary view
- Order submission form
- Responsive user interface

## 🛠 Tech Stack

**Frontend:**
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3

**State Management:**
- React useState
- React useContext

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

git clone https://github.com/NeelimaKancharana/food-order-app.git

### 2️⃣ Navigate into the project folder
cd food-order-app


### 3️⃣ Install dependencies

npm install

### 4️⃣ Run the application

npm start


The app will run on:

http://localhost:3000
